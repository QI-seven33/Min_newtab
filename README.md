# MiniNewTab

为 Chrome 做的轻量新标签页。首页只显示时间、搜索和自己添加的网站快捷方式；点击右下角淡显的设置图标，可调整外观、背景和功能。

## 使用

1. 打开 `chrome://extensions`，开启「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择此项目文件夹。
3. 已安装旧版本时，在原来的扩展卡片上点击刷新，再打开一个新标签页。

项目已包含构建好的 `newtab.js` 和本地图标，加载扩展不需要安装 Node.js 或执行构建。升级时继续使用原项目路径、刷新原扩展，可以沿用原来的本地设置与壁纸。

## 功能

- 默认 Google 搜索；在设置中可切换 Bing、百度、DuckDuckGo。搜索框不显示搜索引擎图标，不提供 Google 服务入口；输入网址会直接访问，空内容不跳转。
- 默认在当前标签页打开；设置中可改为在新标签页打开搜索结果和网站快捷方式。
- 默认不预设网站快捷方式。设置中可新增、编辑、移除及撤销，最多 10 个；首页不显示新增或编辑按钮。网址只接受 HTTP / HTTPS。
- 浅色、深色、跟随系统三种主题模式，五组主题颜色。
- 本地图片与视频壁纸默认不压暗，可在设置中调整；视频播放与暂停按钮也收在设置内。文件保存在设备上，不上传。
- 默认显示时分，可开启同等大小的秒数或 12 小时制；后台暂停时钟定时器和视频播放。系统开启减少动态效果时，视频初始暂停，可在设置中手动播放。
- 自定义签名，设置实时预览，点击保存生效；取消或按 Esc 恢复已保存状态。
- `/` 聚焦搜索，Esc 关闭设置 / 退出输入焦点；按钮和对话框支持键盘操作。搜索提交箭头仅在有输入或获得键盘焦点时显示。
- 同一 Chrome 配置中的新标签页会同步本地设置；正在编辑的设置草稿保留，保存时只合并本次调整的项目。

图片支持 JPG、PNG、WebP、GIF、AVIF，限制 20 MB；视频支持 MP4、WebM，限制 100 MB，实际解码能力取决于 Chrome 支持的编码。壁纸先校验并写入 IndexedDB，成功后才更新配置；保存失败会提示并保留原有设置。兼容旧版本 `ntConfig`、`MiniNewTabDB / imgStore` 中的 base64 图片及 Blob 视频。

本轮更新会移除上轮自动提供且未经修改的示例快捷方式，保留用户添加和修改过的网站；旧版默认的 35% 背景压暗恢复为 0%，其他自定义压暗值保留。

## 本地开发

```sh
npm ci
npm run build
npm test
npm run test:browser
```

修改 `src/app.js`、`src/core.js` 或 `src/storage.js` 后执行构建，然后刷新扩展。HTML 和 CSS 可直接修改。`newtab.js` 是构建产物，不建议直接编辑。

构建使用官方 Material Web 组件，图标来自 Phosphor，全部随扩展打包，不依赖在线 CDN、远程字体或远程脚本。第三方许可见 `THIRD_PARTY_NOTICES.txt`。

浏览器测试使用 Playwright 和已安装的 Chrome，在独立配置目录中通过 Chrome DevTools 协议加载本项目，不接触日常浏览器数据。默认 Chrome 路径为 Windows 的 `C:/Program Files/Google/Chrome/Application/chrome.exe`，其他安装位置可设置 `CHROME_PATH` 环境变量。测试证据输出到 `test-results/`。测试用 `--enable-unsafe-extension-debugging` 参数仅用于独立测试实例，无需修改日常 Chrome 的启动参数。

## 权限与数据

扩展仅申请 `storage` 和 `unlimitedStorage`，用于本机配置与媒体存储；没有新增历史记录、书签、标签页读取或网站访问权限。不加载远程资源，也不发送分析数据。只有点击外部网站或执行搜索时才跳转到相应服务。数据不跨设备同步，移除扩展会清除该扩展的本地数据。

0.2.0 的主要变更：重做首页与设置、补充 Google 搜索及网址直达、快捷方式和主题，改进存储错误处理、旧版数据兼容与后台资源使用。未引入服务工作线程或网页框架。
